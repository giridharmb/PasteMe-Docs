# Paste Me

**A native clipboard manager for macOS.** Paste Me keeps a searchable history of everything you copy (text, rich text, code, links, images, files and colors) and pastes it back exactly as it was copied.

> This repository holds Paste Me's public documentation: privacy notice, terms, support, FAQ and release material. The app's source code is private.

## Highlights

- **Everything you copy, instantly searchable.** Press ⇧⌘V anywhere to open your history. Type to filter, then press ↩ to paste into the app you're using.
- **Pastes with the original formatting.** Paste Me stores every format an app puts on the clipboard, so RTF, HTML, images and files come back intact. ⇧↩ pastes as plain text.
- **Built for code.** Paste Me detects 20+ languages and highlights them with 8 themes. Indentation stays exactly as copied, and line numbers are optional. You can also paste code as highlighted RTF into Notes, Mail or Keynote.
- **Grouped by app.** The Apps sidebar shows clips by the app you copied from. ⌥↑ / ⌥↓ step through apps without touching the mouse.
- **Pins and pinboards.** Keep snippets you reuse. Pinned items are never deleted automatically.
- **"Paste As" transforms.** Change case, convert to camel/snake/kebab case, pretty-print or minify JSON, Base64 or URL encode/decode, make a Markdown link or code block, and more.
- **Private by design.** Paste Me skips passwords that password managers mark as concealed, and ignores apps you exclude. It has no analytics, no tracking and no accounts. [Read the Privacy Notice](PRIVACY.md).
- **Optional iCloud sync.** History, pins and settings sync through your own private iCloud. On a new Mac, everything restores automatically.
- **Free.** No in-app purchases, subscriptions or ads. Every feature is included.
- **Yours to tune.** Choose the layout (shelf or list), fonts, code theme, image background, page size, history size limits, retention and global shortcuts.

## Requirements

- macOS 14 Sonoma or later
- Accessibility permission, only if you want Paste Me to paste for you ([why?](release/accessibility-permission.md))
- An iCloud account, only for sync
