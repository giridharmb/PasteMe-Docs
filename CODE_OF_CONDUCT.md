# Code of Conduct

Be respectful and constructive. Harassment, discrimination and personal attacks aren't tolerated. Maintainers may remove comments or issues that break these rules. Report problems by [opening an issue](https://github.com/giridharmb/PasteMe-Docs/issues).
This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
