# Keyboard shortcuts

## Anywhere (global, configurable in Settings ▸ Shortcuts)

| Shortcut | Action |
|---|---|
| ⇧⌘V | Show clipboard history |
| ⌥⇧⌘V | Paste the clipboard as plain text |
| ⌃⌥V, then 0–9 | **Quick Paste:** paste the item in that slot (number row or keypad; Esc cancels) |
| — | Paste previous item |
| — | Copy selection & pin it |
| — | Show pinned items |
| — | Pause / resume capture |

Paste Me's shortcuts take priority over the same keys in the app you're using. To change that:
- **Settings ▸ Shortcuts ▸ Enable global shortcuts** turns them all off.
- **Let These Apps Keep Their Own Shortcuts** lists apps where Paste Me steps aside while that app is in front, which is useful for virtual machines, remote desktops and games.
- **Restore Default Shortcuts** puts everything back.

### Quick Paste

Quick Paste gives you ten slots, numbered 0–9.
- **Assign an item:** use Settings ▸ Quick Paste, right-click an item in the history panel ▸ **Quick Paste Slot**, or open the menu bar menu ▸ **Quick Paste**.
- **Paste an item:** press ⌃⌥V, then the slot's number. While Paste Me waits (2 seconds by default), a small overlay lists your slots and the number keys go to Paste Me.
- **Keeping items:** an item in a slot is pinned, so history limits never remove it.

## In the history panel

| Shortcut | Action |
|---|---|
| ↩ | Paste the selected item |
| ⇧↩ | Paste as plain text |
| ⌘↩ | Copy without pasting |
| ⌥↩ | Open link or file |
| ⌘1 … ⌘9 | Paste visible item 1–9 on the current page |
| ← → ↑ ↓ | Move the selection (⌘ jumps to the ends) |
| ⌥↑ / ⌥↓ | Previous / next app in the Apps sidebar |
| ⌘0 | Show items from all apps |
| ⌘G | Show / hide the Apps sidebar |
| Page Up / Page Down, ⌘[ / ⌘] | Previous / next page |
| Space, ⌘Y | Preview |
| ⌘P | Pin / unpin |
| ⌘R | Rename |
| ⌘⌫ | Delete |
| ⌘N | New pinboard with the selected item |
| ⇥ / ⇧⇥ | Switch History ▸ Pinned ▸ pinboards |
| ⌘F | Search (or just start typing) |
| Esc | Close preview → clear search/filters → close the panel |
| ⌘, | Settings |
